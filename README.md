# Focal Point MU Plugins

Shared must-use WordPress plugins for the Rayner Focal Point multisite.

This repository is checked out directly at `wp-content/mu-plugins` because
WordPress automatically loads PHP bootstrap files in this directory, but does
not recursively discover plugins in subdirectories.

## Included plugins

### Focal Point PDF Registry

The existing PDF registry provides a shared audit registry for user Coaching,
Feedback, and Aspirations PDFs.

- Bootstrap: `focalpoint-pdf-registry.php`
- Implementation: `focalpoint-pdf-registry/`

The bootstrap currently loads the PDF email-notification module from the
`rayner_focalpoint_mgmt` theme when that file is available. This cross-theme
dependency is intentional existing behaviour and must be considered during
deployment.

### Focal Point EasyCoach LTI

Shared integration foundation between the Focal Point learner sites and
EasyCoach using LTI 1.3, OpenID Connect, OAuth 2.0, JWT and Assignment and
Grade Services (AGS).

- Bootstrap: `focalpoint-easycoach-lti.php`
- Implementation and documentation: `focalpoint-easycoach-lti/`

Version `0.4.0` adds the LTI 1.3 third-party initiated OIDC resource-link
launch, protected RSA signing-key loading and public JWKS publication alongside
the network data model and stable pseudonymous learner mapping. Token and
result routes remain fail-closed placeholders.

The security and protocol implementation belongs in this repository. Learner
interface components remain in the `rayner_focalpoint` theme, and KPI/reporting
integration remains in the `rayner_focalpoint_mgmt` theme.

## Security

Never commit private RSA keys, OAuth credentials, access tokens, learner
result payloads, personal data, environment files, or production logs.

LTI private keys must be supplied through protected environment/server
configuration. Only public key material may be exposed through the platform's
JWKS endpoint.

## Generated files

`wp-migrate-db-pro-compatibility.php` is generated by WP Migrate DB Pro and is
deliberately not tracked. Local backup and log files are also ignored.
